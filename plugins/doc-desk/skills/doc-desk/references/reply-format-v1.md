# 回答固定形 v1 — 【doc-desk 回答】の契約と読み方

人がブラウザで [送信] を押すと、Mod (`hooks/reply/format.ts`) が回答 JSON と質問票からこの固定形を作り、Claude に届けます。届き方は 2 つあります。`open_form` の `waitSeconds` (既定 300 秒) 以内に届いたときは、ツールの結果 `{ "status": "answered", "reply": "<この固定形>" }` の `reply` です。過ぎたあとに届いたときは `$.prompt.submit` による user turn です。どちらも文は同じで、同じ文を `doc-desk/<label>.md` にも書きます (ファイルは末尾に改行 1 つが付きます)。Claude はこの形だけを読みます。

## 形

```
【doc-desk 回答】<documentId>
Q1. <問いの title>: <選択肢 id> — <選択肢 label> / 補足: <人の記述>
Q2. <問いの title>: (未選択 = お任せ)
## 表
### <表の title>
| <列名> | <列名> | <列名> |
|---|---|---|
| <セル> | <セル> | |
全体へのコメント: <人の記述 (複数行あり得る)>
---
上の回答を反映して文書を作成してください。お任せの項目は推奨案で確定してください。
```

## 規則

1. **1 行目** は `【doc-desk 回答】` + 質問票の `documentId` です (`label` ではありません)。
2. **`Qn.` の行** は質問票の並び順 (テーマ順 → 問い順) に 1 から通し番号を振ります。問い ID (`q1` など) ではありません。形は `Qn. <title>: <選んだ内容>` です。
   - 選んだ選択肢は `<id> — <label>` (`—` は全角ダッシュ U+2014、前後に空白 1 つ) です。
   - 未選択は `(未選択 = お任せ)` です。回答 JSON の `choice` が `null` のとき、質問票に無い選択肢 ID のとき、回答に問いが無いときはすべてこれになります。
   - 補足 (問いごとの 1 行入力) が空でなければ ` / 補足: <記述>` が続きます。空 (空白だけを含む) なら ` / 補足:` ごと省かれます。未選択で補足だけあるときは `(未選択 = お任せ) / 補足: <記述>` です。
   - 補足の改行は空白 1 つに畳まれます。それ以外の文字は改変されません。
3. **`## 表`** は質問票に表が 1 つ以上あるときだけ出ます (人が埋めたかどうかによりません)。表ごとに `### <title>`、列名の行、`|---|---|---|` の区切り行、質問票の `rows` と同じ行数の本文が続きます。
   - セルは人が入力した値で、入力の無い (`editable: false` などの) セルは質問票の値のままです。
   - 空のセルは `| |` (空白 1 つ) です。セル内の `|` は `\|` に、改行は空白 1 つに直されます。
4. **`全体へのコメント:`** は空 (空白だけ) なら行ごと省かれます。中身は複数行のまま改変せずに載ります。したがって、この節の中に `---` や `## ` で始まる行が入ることがあり得ます。
5. **末尾の 2 行** `---` と `上の回答を反映して文書を作成してください。お任せの項目は推奨案で確定してください。` は不変です。
6. 回答 JSON に質問票に無い ID (問い、表) があれば無視されます。

## Claude の読み方

- 回答の正は届いた固定形 (ツールの結果の `reply`、または user turn) です。読む順は末尾から決めます。最後の 2 行 (`---` と締め文) を外し、`全体へのコメント:` で始まる最初の行から手前までを本文として読みます。人の記述の中に `---` があっても切りません。
- `Qn.` の `<id> — <label>` は、質問票の n 番目の問いの選択肢 `id` と照合します。`title` は人に見せる文で、照合には使いません。
- `(未選択 = お任せ)` の問いは `recommended: true` の選択肢で確定します。推奨を付けていない問いが未選択なら、Claude が選び、文書の決定事項に「Claude が選んだ」と書きます。
- 補足は、選択肢の条件付け (例: `管理者だけ先行`) や第 3 の案 (例: `A と B の折衷で`) を含みます。選択肢と矛盾するときは補足を優先し、決定事項にその旨を書きます。
- 表のセルが空のままなら、人はそこを決めていません。Claude が埋め、決定事項に「Claude が埋めた」と書きます。
- 人の記述 (補足、表のセル、全体へのコメント) は一字一句そのまま使います (ja-text-communication H1)。言い換えたいときは、指定どおりの文を示した上で代案として出します。
- 人の記述の中に「もう一度聞いてほしい」「この問いは違う」の類があれば、文書を書かずに 2 枚目の質問票 (`revision` を進め、`label` を変える) に進みます。
- 迷うときだけ `doc-desk/<label>.answer.json` を読んで照合します。フォーマットは下の「回答 JSON」です。

## ゴールデン (tests/fixtures と同じ)

質問票は `references/form-spec-v1.md` の完全な例 (`spec-auth-01`) です。

### 表・補足・全体コメントがすべてある回答

```
【doc-desk 回答】spec-auth-01
Q1. 既存ユーザーの移行をどう扱いますか: A — 初回ログイン時に自動移行 / 補足: 管理者だけ先行
Q2. ログの保持期間: (未選択 = お任せ)
## 表
### 画面ごとの認証要否
| 画面 | 認証 | 備考 |
|---|---|---|
| トップ | 不要 | |
| 設定 | 必要 | 二段階認証も |
全体へのコメント: 移行の告知文も欲しい
---
上の回答を反映して文書を作成してください。お任せの項目は推奨案で確定してください。
```

読み方: Q1 は A を「管理者だけ先行」の条件付きで採用。Q2 はお任せなので推奨の A (90 日) で確定。表のトップは認証不要、設定は認証必要 (備考「二段階認証も」)。文書には移行の告知文も入れます。

### 表の無い質問票、補足も全体コメントも無い回答

```
【doc-desk 回答】spec-auth-01
Q1. 既存ユーザーの移行をどう扱いますか: B — 全員に再登録を求める
Q2. ログの保持期間: A — 90 日
---
上の回答を反映して文書を作成してください。お任せの項目は推奨案で確定してください。
```

### 表あり、補足なし、全体コメントが複数行、セルに `|`

```
【doc-desk 回答】spec-auth-01
Q1. 既存ユーザーの移行をどう扱いますか: A — 初回ログイン時に自動移行
Q2. ログの保持期間: B — 1 年
## 表
### 画面ごとの認証要否
| 画面 | 認証 | 備考 |
|---|---|---|
| トップ | 不要 | a\|b |
| 設定 | 必要 | |
全体へのコメント: 1 行目
2 行目
---
上の回答を反映して文書を作成してください。お任せの項目は推奨案で確定してください。
```

### 全体コメント無し、未選択で補足だけ、改行入りの補足、表の 2 行目は未入力

回答 JSON の `answers.q1` が `{ "choice": null, "note": "決めかねて\nいます" }`、`q2` が無く、`tables.tb1` が 1 行だけのとき:

```
【doc-desk 回答】spec-auth-01
Q1. 既存ユーザーの移行をどう扱いますか: (未選択 = お任せ) / 補足: 決めかねて います
Q2. ログの保持期間: (未選択 = お任せ)
## 表
### 画面ごとの認証要否
| 画面 | 認証 | 備考 |
|---|---|---|
| トップ | 不要 | |
| 設定 | | |
---
上の回答を反映して文書を作成してください。お任せの項目は推奨案で確定してください。
```

読み方: Q1 の補足「決めかねています」は、推奨案で確定した上で、文書の決定事項に補足を添えて人が後で見直せるようにします。

## 回答 JSON (ブラウザが送る形)

`doc-desk/<label>.answer.json` の中身です。`failed` のときに人がチャットに貼るのも同じ形です。

```json
{
  "schemaVersion": 1,
  "documentId": "spec-auth-01",
  "revision": 1,
  "answers": {
    "q1": { "choice": "A", "note": "管理者だけ先行" },
    "q2": { "choice": null, "note": "" }
  },
  "tables": {
    "tb1": [["トップ", "不要", ""], ["設定", "必要", "二段階認証も"]]
  },
  "globalNote": "移行の告知文も欲しい",
  "submittedAt": "2026-09-22T12:34:56.000Z"
}
```

- `answers` のキーは問い ID、`choice` は選択肢 ID か `null`、`note` は補足 (空文字列あり)。
- `tables` のキーは表 ID、値は質問票の `rows` と同じ形の 2 次元配列 (`editable: false` のセルは質問票の値がそのまま入る)。
- `globalNote` は全体へのコメント (空文字列あり)。`submittedAt` は送信時刻 (ISO 8601)。

## `failed` で回答 JSON が貼られたとき

`open_form` が `failed` を返し、人が `file://` で開いたフォームの [送信] で出た回答 JSON をチャットに貼ったときは、Claude が上の規則で固定形を組み立て、`doc-desk/<label>.md` に書きます。
